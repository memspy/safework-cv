To add more, for example edge proximity or the edge editor, save the image here and reference it from the README. Avoid parentheses and spaces in new file names, they need URL encoding in Markdown links.

## How to produce screenshots

- Run with `--snapshots out/snapshots`. An annotated JPEG is saved at the start of every alert.
- Run with `--display` and take a screenshot of the window.
- For a short animation, record `--save-video out/annotated.mp4` and convert a segment to a GIF.

Keep images below about 1 MB each.

## Privacy and rights

Use footage that you own or have a licence for. Blur faces or use staged material so that no identifiable person appears. Do not publish screenshots taken from third-party videos without permission.
